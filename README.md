A modern, full-stack web application designed to streamline student registration and data management. Built with a **Java Spring Boot** backend, **MySQL** database via JDBC, and a gorgeous **Glassmorphism** frontend.

## ✨ Features
* **Premium UI/UX:** A stunning, responsive frontend built with vanilla HTML/CSS/JS utilizing glassmorphism, dynamic animations, and abstract AI-generated graphics.
* **RESTful API:** A robust Java Spring Boot backend handling cross-origin requests and data processing.
* **Raw Database Connectivity:** Implemented pure JDBC `PreparedStatement` logic for secure MySQL data insertion without relying on automated ORMs.
* **Asynchronous Flow:** Uses the JavaScript Fetch API to transmit data seamlessly without page reloads, accompanied by custom loading animations.

## 🚀 How to Run Locally

### Prerequisites
* Java JDK 17+
* MySQL Server (running on port 3306 with root/root credentials)

### 1-Click Start (Windows)
Simply double-click the `run.bat` file in the root directory. It will automatically download Maven (if missing), build the project, and start the Spring Boot embedded Tomcat server.

Navigate to `http://localhost:8080` to view the application!
